# NoMineshaft (Works for Vanilla and LethalLevelLoader)

**NoMineshaft** removes mineshaft interior from the game (ideally screaming hamster).

# Requirements for mod to build

BepInExPack mod and LobbyCompatibility.

# Requirements to play

If host has this mod on everyone else has to have it to prevent chaos.

# Build

 ```bash
   ./build.sh
   ```
